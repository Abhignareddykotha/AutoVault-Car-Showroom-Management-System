# 🚗 AutoVault - Car Showroom Management System

## 📖 Overview
AutoVault is a Java console-based application developed using Object-Oriented Programming (OOP). It allows users to manage a simple car showroom inventory through a menu-driven interface.

---

## ✨ Features

- ➕ Add a new car
- 📋 View all available cars
- 🚪 Exit the application
- 🧱 Object-Oriented Design using Classes and Objects
- 📦 Stores car data using ArrayList

---

## 🛠️ Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- VS Code

## ▶️ How to Run

1. Clone the repository.
2. Open the project in VS Code.
3. Compile the Java files.
4. Run `Main.java`.
5. Use the menu to add and view cars.
